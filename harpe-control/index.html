01 / RECOVERY

Physical recovery guide

  1. Export readable settings in normal mode, then disconnect.
  2. Unplug USB and set the switch to OFF.
  3. Hold Left + Right + Wheel click + DPI, then plug in USB.
  4. Release after about three seconds, then connect the bootloader below.

This combination can reset settings. Back up readable settings first.

Only known SHA-256 images are accepted. No automatic retry or bootloader exit on errors.

Browser flasher: offline-tested protocol port; hardware validation of this browser implementation is pending.
